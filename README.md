# 🚀 Jenkins + Docker + EC2 - CI/CD Pipeline

> Project by Soundhar | Elevate Labs Task 1

A complete CI/CD pipeline that automates building and deploying a Node.js application using Jenkins, Docker, and AWS EC2.

### 🛠️ Tech Stack
- **Jenkins** - For CI/CD Automation
- **Docker** - For Containerization
- **AWS EC2** - For Hosting (Ubuntu)
- **Node.js + Express** - Sample App
- **GitHub** - Source Code Management

### 🏗️ Architecture
`Developer Push -> GitHub -> Jenkins (Webhook) -> Docker Build -> Docker Run -> Live on EC2:8000`
